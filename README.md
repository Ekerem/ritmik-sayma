# Ritmik Sayma – Venüs'ün Uzay Macerası

3. sınıf öğrencileri için ritmik sayma oyunu. Maskeli süper kedi **Venüs**, ay yüzeyinde koşarken sadece seçilen sayının katlarının yazdığı kutulara kafa atar: önce 10 katına kadar ileri (8, 16 … 80), sonra geriye (80, 72 … 8). Sonunda kedi başlı uzay gemisi **VENÜS-1** ile havalanır.

- 2'şer, 3'er, 4'er, 5'er, 6'şar, 7'şer, 8'er, 9'ar ritmik sayma
- Yanlış kutu → ateş; ilk hatada pelerinli kötü köpek kovalamaya başlar, ikinci hatada yakalar
- Her 10 yıldızda +1 can
- Yavaş / Normal / Hızlı hız seçeneği, tam ekran, çıkış ve 🔄 Güncelle butonu
- İnternetsiz çalışır (son açılan sürüm cihazda saklanır)
